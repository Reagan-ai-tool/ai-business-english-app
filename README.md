## What this project does

This is a Streamlit web app that rewrites text into professional business English.

## How it works

1. User enters text in the web UI
2. The app sends the text to OpenAI API
3. The model rewrites it in professional tone
4. The result is shown instantly

## Tech stack

- Python
- Streamlit
- OpenAI API

## Project structure

- app/ : UI and business logic
- api/ : API-related logic
- tests/ : basic validation tests
